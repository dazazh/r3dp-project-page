# Images Directory

请将以下图片放置在此目录中：

## 必需图片

| 文件名 | 描述 | 论文来源 |
|--------|------|----------|
| `teaser.png` | 开场图 - 关键模块和性能对比 | Figure 1 |
| `architecture.png` | R3DP 整体架构图 | Figure 2 |
| `tfpnet.png` | TFPNet 架构和训练目标 | Figure 3 |
| `depth_comparison.png` | 深度图可视化对比 (VGGT vs TFPNet) | Figure 4 |
| `real_world_setup.png` | 真实世界实验平台和任务 | Figure 5 |

## 图片要求

- **格式**: PNG 或 JPG (推荐 PNG 以保证质量)
- **分辨率**: 建议宽度至少 1200px
- **大小**: 单张图片建议 < 2MB (可使用 TinyPNG 压缩)

## 可选图片

如果需要添加更多图片，可以在 `index.html` 中添加相应的 `<img>` 标签：

```html
<img src="images/your_image.png" alt="Description">
```

## 图片压缩工具

- [TinyPNG](https://tinypng.com/) - 在线压缩
- [Squoosh](https://squoosh.app/) - Google 开发的图片压缩工具
